Web Development Group Project (Local Machine)

Type: Group Project (2 people)

Stack: Node.js, Express, MongoDB, Socket.IO

My Role: Backend Developer

Status: Local demo (source code available)

During my fourth semester, a classmate and I developed a web-based car dealership application as a group project. The platform allows users to register and log in to browse available vehicles or list their own cars for sale. The system was designed to theoretically streamline the car dealership transaction process by enabling direct communication between buyers and sellers through a private chat feature, reducing the need for in-person visits. This project was developed for academic purposes and is not affiliated with any commercial organization. The application operates using a locally hosted MongoDB database and is intended to be run in a local development environment.

My Role:

I served as the Backend Developer, responsible for integrating the frontend components with the database and server-side logic. My role focused on ensuring accurate data flow, correct routing, and maintaining data integrity across all system features.

My Personal Contributions:

  1. Implemented user authentication (sign-up and login) using Node.js and MongoDB
  2. Developed server-side application logic
  3. Built the car listing and offer upload system, including image uploads and price editing
  4. Integrated a real-time private chat feature using Socket.IO

  1. Install Node.js
  2. Install MongoDB
  3. Run npm install
  4. Run npm start

Android App Group Project

Type: Group Project (5 people)

Stack: Java, Android Studio, SQLite

My Role: Backend Developer

Status: Project Folder and APK (Both files available)

During my fifth semester, I collaborated with four classmates to develop an Android application using Android Studio. The project topic was open-ended, and our team chose to create a simple dictionary application. The app features a user authentication system, with user data stored locally using an SQLite database. It utilizes Android fragments to manage multiple views, including:

  • A word list displaying saved vocabulary and definitions
  • A bookmarks section for favorited words
  • A user profile screen
  • A music player that allows background audio inside and outside the app while logged in

My Role:

I worked as a Backend Developer, focusing on connecting the user interface components to the local database. I ensured that all user data was stored correctly, that each user was associated with a unique identifier, and that features such as the music player functioned reliably.

My Personal Contributions:

  1. Implemented user authentication, list display, and media playing using Java
  2. Designed and developed the SQLite database schema
  3. Created class constructors to standardize and structure data storage
  4. Ensured user-specific data isolation for personal dictionaries
  5. Integrated a background music player feature
